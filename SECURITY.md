# Security policy

## Supported versions

AgenticGraph Vector (`shahzad/agenticgraph-vector`) is before 1.0. Only the latest minor version gets security fixes.

## Report a vulnerability

Do not open a public issue for a security problem.

Use GitHub private vulnerability reporting: go to the [Security tab](https://github.com/shahzad-io/agenticgraph-vector/security) of this repository and click "Report a vulnerability". Only the maintainers can see the report.

Include:

- The affected version.
- The steps to reproduce the problem.
- What an attacker can do.

You get a reply within 7 days. When the fix is released, the advisory is published with credit to you, unless you ask us not to name you.
